# Gym Membership & Retention Analysis

## Project Overview
Analyzed 150 gym members data to understand why members leave and how to retain them.

## Key Findings
- Overall Retention Rate: 68%
- At-Risk Members: 32% members need attention
- Best Performing Plan: Annual Plan has highest retention
- Peak Joining Month: January

## Tools Used
- MS Excel - Data Cleaning, Pivot Tables, VLOOKUP, Charts
- Power BI - Interactive Dashboard
